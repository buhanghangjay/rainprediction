# 🌧️ Manila Rain Frequency Prediction

An end-to-end weather analytics and machine learning project that analyzes how temperature relates to rain frequency in Manila.

The project transforms a raw weather dataset into a cleaned analytical dataset, performs Manila-specific exploratory analysis, trains and evaluates regression models, and exposes the results through an interactive Streamlit web application.

---

## 🎯 Problem Statement

The weather dataset contains observations from different areas within Manila together with missing values, possible duplicates, and inconsistent formatting.

The objective is to preprocess the dataset and investigate how temperature affects rain frequency specifically in Manila.

A machine learning model is then used to estimate rain frequency based on temperature.

---

## 🚀 Project Highlights

This project goes beyond a standard machine learning notebook by providing:

- Data quality assessment
- Missing-value handling
- Duplicate detection and removal
- Text and numeric data standardization
- Manila-specific weather analysis
- Temperature vs. rain-frequency visualization
- Regression modeling
- Model evaluation using RMSE and R²
- Cross-validation
- Multiple-model comparison
- Actual vs. predicted visualization
- Interactive What-If Weather Simulator
- Dataset chatbot
- Downloadable cleaned dataset
- Interactive Streamlit web application
